## 🌟 درباره سامانه

**CampusGuard** یک نرم‌افزار تحت وب سبک، سریع و بهینه‌سازی‌شده برای گیت‌های حراست و انتظامات دانشگاه‌ها و مجتمع‌های بزرگ است. 

این سیستم با رابط کاربری اختصاصی برای ثبت انواع **پلاک‌های ملی ایران** و تردد **عابرین پیاده** طراحی شده و به لطف معماری ذخیره‌سازی دوگانه (**دیتابیس ابری Turso + حافظه محلی مرورگر**)، عملکردی پایدار و بدون وقفه را حتی در زمان قطع کامل اینترنت تضمین می‌کند.

---

## ✨ قابلیت‌های کلیدی سامانه

### 🚗 مؤلفه استاندارد و هوشمند پلاک ملی ایران
* **تغییر خودکار رنگ پلاک بر اساس نوع کاربری خودرو:**
  * 🟡 **زرد:** تاکسی (`ت`)، حمل‌ونقل عمومی (`ع`)، ادوات کشاورزی (`ک`)
  * 🟢 **سبز:** پلیس (`پ`)، سپاه (`ث`)، وزارت دفاع (`ز`)، ستاد کل (`ف`)
  * 🔴 **قرمز:** پلاک دولتی (`الف`)، خودروهای تشریفات (`تشریفات`)
  * 🔵 **سرمه‌ای / آبی روشن:** ارتش (`ش`)، دیپلماتیک (`D`)، سفارت و کنسولگری (`S`)
  * ⚪ **سفید:** خودروهای شخصی و سهمیه معلولین و جانبازان (`♿`)
* **انتقال خودکار فوکوس و تبدیل ارقام:** تایپ آسان با هدایت هوشمند نشانگر و تبدیل خودکار اعداد انگلیسی به فارسی.

### ⚡ دیتابیس هیبریدی (ابری + آفلاین پایدار)
* اتصال مستقیم به دیتابیس ابری توزیع‌شده **Turso (LibSQL)** از طریق پروتکل بهینه Pipeline HTTP بدون نیاز به هیچ کتابخانه یا SDK سنگین.
* **پایداری در زمان قطعی شبکه:** ذخیره خودکار در `localStorage` در صورت عدم دسترسی به اینترنت و همگام‌سازی بلافاصله پس از برقراری مجدد ارتباط.

### 🧠 حافظه هوشمند و تکمیل خودکار (Auto-Fill)
* شناسایی خودکار مشخصات مراجعین دائمی؛ با وارد کردن پلاک یا نام فرد، فیلدهای نام، وابستگی سازمانی (استاد، کارمند، دانشجو، پیمانکار)، دسته خودرو و علت تردد به شکل خودکار پر می‌شوند.

### 📅 موتور محاسباتی تقویم جلالی (بدون کتابخانه جانبی)
* تبدیل ریاضی و فوق‌العاده سریع تاریخ‌های شمسی و میلادی در ماژول `jalali.js` بدون نیاز به Moment.js یا Date-fns.
* **فیلترهای پیشرفته زمانی بر اساس شیفت:**
  * 🌅 شیفت صبح (`۰۶:۰۰` تا `۱۴:۰۰`)
  * 🌇 شیفت عصر (`۱۴:۰۰` تا `۲۲:۰۰`)
  * 🌙 شیفت شب (`۲۲:۰۰` تا `۰۶:۰۰`)
  * ⏱️ بازه‌های زمانی و تاریخی دلخواه + گزینه‌های سریع (امروز، دیروز، ۷ روز اخیر، ماه جاری)

### 📱 طراحی ریسپانسیو و دوگانه (موبایل و دسکتاپ)
* **نمای دسکتاپ:** جدول تجمیعی و با تراکم بالا مناسب مانیتورهای ایستگاه نگهبانی.
* **نمای موبایل و تبلت:** تبدیل خودکار ردیف‌ها به ساختار کارتی (Card View)، استفاده از منوهای کشویی پایین‌صفحه (Bottom Sheets) و دکمه شناور (FAB) برای سهولت استفاده روی تبلت‌های لمسی یا گوشی نگهبان.

### 👮 مدیریت کشیک و ماموران انتظامات
* امکان تعریف شیفت‌ها و ماموران حراست و ثبت خودکار نام مامور ثبت‌کننده در هر تردد.

## 🚀 راهنمای نصب و راه‌اندازی

این پروژه **کامپایل، بیلد یا پکیج‌منیجر نیاز ندارد** و به راحتی با هر وب‌سروری قابل اجراست.

```bash

code

با زدن دکمه تست اتصال و ذخیره، جداول به صورت خودکار ایجاد و همگام می‌شوند.
🗄️ ساختار پایگاه داده (SQL)
جداول دیتابیس به صورت خودکار بر روی Turso / SQLite به شرح زیر ساخته می‌شوند:
code
SQL
-- جدول ثبت ترددها
CREATE TABLE IF NOT EXISTS campus_records (
  id INTEGER PRIMARY KEY,
  traffic_type TEXT,            -- نوع تردد: 'VEHICLE' یا 'PEDESTRIAN'
  person_category TEXT,         -- رده مراجع: 'STAFF', 'FACULTY', 'STUDENT', 'GUEST', 'CONTRACTOR'
  person_name TEXT,             -- نام مراجع
  plate_part1 TEXT,             -- دو رقم اول پلاک
  plate_letter TEXT,            -- حرف پلاک
  plate_part2 TEXT,             -- سه رقم پلاک
  plate_city TEXT,              -- کد شهر/ایران
  plate_full TEXT,              -- متن تجمیعی پلاک
  vehicle_category TEXT,        -- دسته خودرو (سواری، وانت، مینی‌بوس و...)
  vehicle_model TEXT,           -- مدل خودرو
  status TEXT,                  -- وضعیت: 'ACTIVE' (حاضر) یا 'EXITED' (خارج‌شده)
  entry_jalali_date TEXT,       -- تاریخ ورود شمسی
  entry_time_display TEXT,      -- ساعت ورود
  exit_time TEXT,               -- زمان ایزوی خروج
  exit_jalali_date TEXT,        -- تاریخ خروج شمسی
  exit_time_display TEXT,       -- ساعت خروج
  guard_name TEXT,              -- نام مامور ثبت‌کننده
  guard_shift TEXT,             -- شیفت مامور
  notes TEXT,                   -- علت مراجعه / هماهنگ‌کننده
  created_at TEXT
);

-- جدول ماموران انتظامات
CREATE TABLE IF NOT EXISTS campus_guards (
  id INTEGER PRIMARY KEY,
  name TEXT,
  shift_name TEXT,
  shift_hours TEXT
);

-- جدول مشخصات مراجعین دائمی (حافظه تکمیل خودکار)
CREATE TABLE IF NOT EXISTS campus_profiles (
  profile_key TEXT PRIMARY KEY,

  person_category TEXT,
  plate_part1 TEXT,
  plate_letter TEXT,
  plate_part2 TEXT,
  plate_city TEXT,
  plate_full TEXT,
  vehicle_category TEXT,
  vehicle_model TEXT,
  default_notes TEXT,
  updated_at TEXT
);
